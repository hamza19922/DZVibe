# DZVibe 🇩🇿

A professional Algerian short-video app built with Expo and React Native.

## Current milestone
- Vertical short-video feed
- Real video playback with `expo-video`
- DZVibe branding and Arabic-first UI
- Android EAS build profiles
- GitHub-connected project

## Next milestones
- Supabase authentication and database
- Video upload/storage
- Likes, comments, follows, profiles
- Algerian discovery and moderation
- Notifications and analytics
